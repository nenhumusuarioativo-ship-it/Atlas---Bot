# Atlas---Bot

## Códigos de erro

- `100`: falha ao executar um comando.
- `101`: seleção recebida não existe nos dados; o log inclui o valor recebido.
- `102`: posição informada não está disponível.
- `103`: intervalo de OVR inválido.
- `104`: busca válida sem resultados.
- `105`: falha ao navegar pelas páginas.
- `106`: falha ao responder ou atualizar uma interação.
- `107`: falha ao processar a busca por OVR.
